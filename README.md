# معرض أحمد كمال - Ahmad Kamal Store

متجر إلكتروني عربي احترافي بالكامل مع لوحة تحكم متكاملة (CMS).

## التشغيل

هذا الموقع ثابت بالكامل (Static SPA) ويعمل بدون أي خادم أو قاعدة بيانات.

### الطريقة الأسرع
افتح ملف `index.html` في المتصفح مباشرة.

### مع خادم محلي (موصى به)
```
# بـ Python
python -m http.server 8000

# أو بـ Node
npx serve .

# ثم افتح
http://localhost:8000
```

## الصفحات

| الرابط | الوصف |
|--------|-------|
| `index.html` | واجهة المتجر (العملاء) |
| `admin.html` | لوحة التحكم (الإدارة) — دخول: `admin` / `admin` |

## البنية

```
/
├── index.html              # واجهة المتجر
├── admin.html              # لوحة التحكم
└── assets/
    ├── css/
    │   ├── storefront.css  # تصميم المتجر
    │   └── admin.css       # تصميم لوحة التحكم
    ├── js/
    │   ├── store-data.js   # طبقة البيانات (localStorage)
    │   ├── utils.js        # أدوات مساعدة (تنسيق، أيقونات)
    │   ├── storefront.js   # منطق المتجر
    │   └── admin.js        # منطق لوحة التحكم
    └── img/                # الصور (اختياري)
```

## البيانات

تُحفظ جميع البيانات في `localStorage` بالمتصفح:
- المنتجات، الفئات، الطلبات
- الكوبونات، إعدادات المتجر
- سلة المشتريات والمفضلة

للانتقال إلى قاعدة بيانات حقيقية لاحقاً، يكفي استبدال دوال `Store.*` في `store-data.js` بطلبات API.

## المميزات

### واجهة المتجر
- ✅ تصميم عربي RTL احترافي
- ✅ متجاوب مع الجوال والتابلت والكمبيوتر
- ✅ بانر متحرك، فئات، منتجات مميزة/جديدة/تخفيضات
- ✅ بحث فوري، فلاتر سعر وفئة
- ✅ صفحة منتج مع خيارات (مقاس/لون) وأسعار مستقلة
- ✅ سلة جانبية، إتمام شراء، دفع عند الاستلام
- ✅ طلب عبر واتساب (رسالة جاهزة)
- ✅ تتبع الطلب بحالة مرئية
- ✅ تحميل فاتورة PDF
- ✅ قائمة مفضلة

### لوحة التحكم
- ✅ لوحة معلومات مع KPIs
- ✅ إحصائيات وتحليلات بمخططات
- ✅ إدارة المنتجات (CRUD) مع صور متعددة وخيارات
- ✅ إدارة الفئات (رئيسية وفرعية)
- ✅ إدارة الطلبات وتغيير الحالة
- ✅ إدارة العملاء
- ✅ إدارة الكوبونات (نسبة/مبلغ، تاريخ انتهاء، حد استخدام)
- ✅ إدارة البانر الرئيسي
- ✅ إعدادات المتجر (اسم، شعار، ألوان، تواصل، شبكات اجتماعية)
- ✅ نسخ احتياطي/استيراد/إعادة تعيين
